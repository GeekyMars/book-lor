## 🟡 Требует доработки
*Сюда автоматически попадают все файлы из проекта, у которых в свойствах статус не указан, либо указан как «черновик» / любой другой, кроме «утверждено».*

```dataview
TABLE type AS "Тип", этап AS "Текущий этап"
FROM "20_Areas/Будущая книга"
WHERE status != "утверждено" OR !status
WHERE file.name != "00_Главный Дашборд Проекта"
SORT file.mtime DESC
```
